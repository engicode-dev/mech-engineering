# Кронштейн сварной

**Описание:** Учебно-технический кейс. Полный инженерный цикл: от ручного расчёта до технологической документации.

**Что внутри:**
- Ручной расчёт на прочность и жёсткость (эпюры Q и M).
- CAE-анализ (FreeCAD + CalculiX): напряжения фон Мизеса, перемещения.
- Конструкторская документация (сборочный чертёж, спецификация по ГОСТ).
- Технологическая документация (маршрутные и операционные карты по ЕСТД).
