# Кронштейн сварной

**Описание:** Учебно-технический кейс. Полный инженерный цикл: от ручного расчёта до технологической документации.

## 📌 Задача
Спроектировать сварной кронштейн для крепления осветительного прибора.
- **Масса груза:** 15 кг
- **Динамический коэффициент:** 1,5
- **Вылет:** 300 мм
- **Материал:** Сталь Ст3сп

## 📂 Состав работы
1. **Ручной расчёт:** эпюры Q и M, подбор сечения, проверка прогиба, расчёт сварного шва.
2. **CAE-анализ (FreeCAD + CalculiX):** напряжения фон Мизеса, перемещения.
3. **Документация:** сборочный чертёж, спецификация, маршрутные и операционные карты (ЕСТД).

## 📊 Результаты
| Параметр | Ручной расчёт | CAE-анализ |
| :--- | :--- | :--- |
| Напряжение | 39,73 МПа | 12,27 МПа |
| Прогиб | 1,19 мм | 2,07 мм |

*Расхождение объясняется различием расчётных схем (идеальная консоль vs податливая заделка).*
